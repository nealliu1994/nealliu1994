## 💡 Selected Projects

### RansomChat Negotiation Analysis

**Data Analytics · Python · SQL · PostgreSQL**

An analysis of historical ransomware negotiation conversations conducted as part of a university industry project. The findings informed recommendations for improving the realism of an AI-powered ransomware negotiation simulator.

- Processed and analysed **74 conversations containing 3,929 messages**.
- Investigated negotiation patterns through message-level and conversation-level features.
- Developed reproducible workflows for data cleaning, feature engineering, and analysis.

[Explore the project](https://github.com/nealliu1994/ransomchat-negotiation-analysis)

### Vegau — Vegan Restaurant Discovery Platform

**Full-Stack Development · React · Node.js · Express · MongoDB**

A university project involving the development of a vegan restaurant discovery platform across web and mobile applications.

- Developed a React frontend and RESTful backend using Node.js and Express.
- Designed MongoDB data models and implemented JWT authentication, role-based access control, search, and filtering.
- Extended the platform into a mobile application using React Native and Expo.
